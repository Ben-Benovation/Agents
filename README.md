# Agents — כוח העבודה הדיגיטלי

ריפו זה מרכז את **הסוכנים** (העוזרים הדיגיטליים) שאנחנו מגייסים ומפעילים.
כל סוכן מגויס באמצעות הסקיל **`agent-hiring`** (לשעבר `Hire_Agent`) שנמצא ב-[`.claude/skills/agent-hiring/`](.claude/skills/agent-hiring/),
מקבל שם ותיקייה ייעודית, ומשויך ל**מחלקה**.

## מבנה הריפו

ההיררכיה היא תמיד בת שלוש רמות:

```
Agents/                     ← הריפו (כלל הסוכנים)
└── <מחלקה>/                ← מחלקה (למשל: Marketing, Operations, Finance)
    └── <שם הסוכן>/         ← סוכן בודד
        ├── AGENT.md         ← כרטיס הסוכן: שם, תפקיד, כלים, תאריך גיוס
        └── ...              ← קבצי עבודה, הנחיות, נכסים של הסוכן
```

- **מחלקה** מקבצת סוכנים בעלי תחום אחריות משותף.
- **שם הסוכן** הוא תיקייה ייעודית שמכילה את כל מה שקשור אליו.

## איך מגייסים סוכן חדש

1. מריצים את הסקיל `agent-hiring`.
2. עוברים את הראיון (Interview) שבסקיל ומפיקים **Role Dossier** מלא.
3. בוחרים **שם** למחלקה (או משתמשים במחלקה קיימת) ו**שם** לסוכן.
4. יוצרים תיקייה `<מחלקה>/<שם הסוכן>/` על בסיס התבנית שב-[`_templates/agent/`](_templates/agent/),
   ומצרפים את ה-Dossier וה-System Prompt שנגזר ממנו.
5. ממלאים את `AGENT.md` בפרטי הסוכן.

**דוגמה חיה:** הסוכן הראשון שגויס — [`Finance/Expense-Prep-Agent/`](Finance/Expense-Prep-Agent/) —
מדגים את התהליך המלא מקצה לקצה.

## מנהל הסוכנים

התיקייה [`manager/`](manager/) שמורה ל**מנהל של כלל הסוכנים** — שכבת ניהול שתתאם,
תתעדף ותמדוד את עבודת כל הסוכנים לאורך המחלקות. תוכן מפורט יתווסף בהמשך.

## תיקיות שירות

| תיקייה | מטרה |
| --- | --- |
| `manager/` | ניהול-על של כל הסוכנים |
| `_templates/` | תבניות ליצירת סוכן חדש (לא מחלקה אמיתית) |
| `.claude/skills/` | הסקילים של הריפו — כולל `agent-hiring`, תהליך הגיוס |
