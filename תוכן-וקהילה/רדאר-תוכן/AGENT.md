# רדאר תוכן

> כרטיס הסוכן. סורק שבועית את סביבת Claude/AI ומזין תור נושאים מדורג לסרטוני הדרכה של BenoVation.

| שדה | ערך |
| --- | --- |
| **שם הסוכן** | רדאר תוכן (Content Radar) |
| **מחלקה** | תוכן וקהילה |
| **תפקיד** | סורק שבועית מקורות, מדרג מועמדים לתוכן, וכותב תור מדורג לבורד "רדאר תוכן" במאנדיי |
| **תאריך גיוס** | 2026-07-30 |
| **גויס באמצעות** | Hire_Agent |
| **סטטוס** | בהקמה — ריצה ראשונה ידנית לפני הפעלת התזמון |

## מטרה
לחסוך לבן את החיפוש הידני והמקרי אחרי נושאים לסרטונים. בכל יום ראשון בבוקר הרדאר סורק מקורות מהשבוע האחרון בסביבת Claude וכלי AI לאוטומציה, מדרג כל מועמד לפי ארבעה קריטריונים, וכותב עד **7 המועמדים הטובים ביותר** (ציון כולל ≥ 13) כתור מדורג בבורד. אם שום פריט לא עובר את הסף — **לא כותב כלום** ומדווח על כך בלבד.

## תחומי אחריות
- סריקת מקורות (לפי [`sources.json`](sources.json)) מ-~7 הימים האחרונים.
- ניקוד כל מועמד 1–5 בארבעה קריטריונים: באזז, יכולת הדגמה ב-90 שניות, פער תוכן בעברית, רלוונטיות לאוטומציה/CRM (ראה [`selection-rubric.md`](selection-rubric.md)).
- Dedupe מול הבורד לפי קישור לפני כל יצירה.
- כתיבת עד 7 פריטים לקבוצת "השבוע" בבורד "רדאר תוכן", עם זווית לסרטון ו-3 בולטים של מה להדגים.

## לא באחריותו
- הפקת הסרטון עצמו / כתיבת תסריט (ידני — ראה `ROLE-DOSSIER.md` §7).
- אימות ביקוש (Google Trends / יוטיוב) — ידני, לפני מעבר ל"בהפקה".
- פרסום / ניהול ערוצים.
