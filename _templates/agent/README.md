# תבנית סוכן

תיקייה זו היא **תבנית** ליצירת סוכן חדש — היא אינה מחלקה או סוכן אמיתי.

## שימוש

1. העתק את התיקייה הזו אל היעד: `<מחלקה>/<שם הסוכן>/`.
2. ערוך את `AGENT.md` ומלא את פרטי הסוכן.
3. הוסף בתיקיית הסוכן כל קובץ עבודה, הנחיה או נכס רלוונטי.

מבנה מומלץ לתיקיית סוכן:

```
<מחלקה>/<שם הסוכן>/
├── AGENT.md      ← כרטיס הסוכן (חובה)
├── skills/       ← סקילים/הנחיות ייעודיות (רשות)
└── work/         ← תוצרים וקבצי עבודה (רשות)
```
