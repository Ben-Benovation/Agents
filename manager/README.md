# מנהל הסוכנים

תיקייה זו שמורה ל**מנהל של כלל הסוכנים** — שכבת ניהול-על מעל כל המחלקות והסוכנים.

תחומי אחריות מתוכננים:

- **מיפוי** — רשימה מתעדכנת של כל הסוכנים, מחלקותיהם ותפקידיהם.
- **תיאום** — חלוקת משימות בין סוכנים והעברת עבודה ביניהם.
- **תעדוף** — קביעת סדרי עדיפויות רוחביים.
- **מדידה** — מעקב אחר ביצועי הסוכנים.

> התוכן יתמלא ככל שיצטרפו סוכנים ומחלקות.
